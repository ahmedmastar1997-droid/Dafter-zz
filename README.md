# دفتر الدرجات الذكي — النشر والتحديث

## النشر الأول
1. ارفع كل ملفات هذا المجلد إلى جذر مستودع GitHub.
2. Settings ← Pages ← الفرع main والمجلد root.
3. افتح الرابط وثبّت البرنامج. لا تغيّر الرابط لاحقاً (البيانات محفوظة لكل رابط).

## إصدار تحديث جديد
1. عدّل `index.html` (أو أي ملف).
2. شغّل: `python bump.py 1.2.0 "وصف الجديد"` (يغيّر الرقم داخل index.html ويكتب version.json).
3. ارفع التغييرات (commit + push).

## عند المستخدم
- **لا يُحدَّث البرنامج تلقائياً أبداً.** يفحص البرنامج version.json عند الفتح ويعرض رقم آخر إصدار في الإعدادات ← التحديثات فقط، دون شريط أو إشعار.
- يضغط المستخدم «تحديث الآن» بنفسه فتُحفظ نسخة احتياطية (آخر ٣) ثم تُحمَّل الملفات الجديدة ويُعاد فتح البرنامج.
- ملف sw.js ثابت ولا يُعدَّل بين الإصدارات، وهذا ما يمنع التحديث الصامت.
- قاعدة البيانات (IndexedDB) لا يمسها التحديث.
- ملاحظة انتقالية: المستخدمون الذين ثبّتوا نسخة قديمة (قبل 1.12.0) سيأخذون ملف sw.js الجديد مرة واحدة تلقائياً من المتصفح.

## التثبيت كبرنامج على الجوال
- لا يمكن تثبيت ملف `artifact-version.html` ولا فتح `index.html` من الملفات: التثبيت يحتاج رابط https.
- أسهل طريقة: ارفع **محتويات مجلد pwa** إلى GitHub Pages (الخطوات أعلاه) أو إلى Vercel (سحب المجلد وإفلاته)، ثم افتح الرابط من Chrome في الأندرويد.
- في الإعدادات ستجد بطاقة «تثبيت كبرنامج» وفيها زر التثبيت. أو من قائمة Chrome (⋮) ← «تثبيت التطبيق».
- آيفون: Safari ← المشاركة ← «إضافة إلى الشاشة الرئيسية».
- البيانات محفوظة لكل رابط. عند الانتقال من النسخة القديمة إلى الرابط الجديد استعمل «نسخة احتياطية» ثم «استعادة».
- لتحويله إلى ملف APK: بعد النشر استعمل موقع PWABuilder.com بإدخال الرابط.

## كيف تُحدِّث البرنامج (٣ خطوات تلقائية)
1. ارفع ملفات النسخة الجديدة (محتويات `pwa-deploy.zip`) إلى GitHub Pages أو Vercel، مع استبدال القديمة.
2. افتح البرنامج على جوالك (بإنترنت). سيظهر في الصفحة الرئيسية «🔔 يتوفر إصدار جديد» (أو من الإعدادات ← التحديثات ← فحص الآن).
3. اضغط **تحديث الآن**، فيُنفَّذ تلقائياً:
   - ① حفظ نسخة احتياطية من بياناتك (داخل البرنامج، وملف على جهازك إن أبقيت الخيار مفعّلاً).
   - ② حذف ملفات النسخة القديمة من الجهاز (البيانات لا تُحذف أبداً).
   - ③ تثبيت النسخة الجديدة وإعادة تشغيل البرنامج.
4. بعد إعادة التشغيل تظهر رسالة تؤكد أن عدد الطلبة والدرجات (ومنها اليومية) كما كان قبل التحديث. وإن لاحظ نقصاً ينبّهك لاستعادة النسخة الاحتياطية.

ملاحظات:
- لا يُحذف شيء قبل التأكد من وصول الملفات الجديدة سليمة؛ فإن انقطع الإنترنت أو لم تصل الملفات تبقى النسخة الحالية كما هي.
- أول مرة: النسخة المثبتة عندك الآن تحدّث نفسها بآلية سابقة مشابهة، وتظهر الواجهة الجديدة ذات الخطوات الثلاث بعد هذا التحديث.

## الأيقونة (1.26.0)
- أيقونة جديدة: دفتر مفتوح + مخطط أعمدة صاعد + علامة صح، بأسلوب ثلاثي الأبعاد ناعم وأخضر فاتح، بلا أي نص.
- الملفات: `icon.svg` و`icon-192.png` و`icon-512.png` (عادية)، و`icon-maskable-192.png` و`icon-maskable-512.png` (لأندرويد بحواف تقصّها الهاتف)، و`apple-touch-icon.png` (آيفون).
- بعد التحديث قد تبقى الأيقونة القديمة على الشاشة الرئيسية: أندرويد يحدّثها أحياناً من تلقاء نفسه؛ وإن لم يحدث فاحذف الاختصار القديم وأعد «تثبيت التطبيق». في آيفون احذفه وأعد «إضافة إلى الشاشة الرئيسية».

## الكاميرا (1.27.0)
1. من اليومي أو الشهري اضغط «📷 كاميرا»، واختر العمود المستهدف.
2. وجّه الكاميرا بحيث يقع الاسم والدرجة داخل **الإطار الأخضر**، ثم اضغط «📸 تثبيت وقراءة». تتثبّت الصورة وتُقرأ البيانات.
3. تظهر القراءة (الاسم + الدرجة + الدقة). صحّح الدرجة إن لزم واضغط «✓ اعتماد» — وبعد الاعتماد يُلغى التثبيت تلقائياً لتضع الورقة التالية. إن كانت في الخانة درجة سابقة يحذّرك ولا يستبدلها إلا بموافقتك.
4. إن لم تُقرأ بدقة: «🔁 إعادة المحاولة» (حتى ٣ مرات بتحسين الصورة)، ثم «✍ إدخال يدوي»: ابحث عن الاسم بالكتابة أو تصفّح القائمة، واكتب الدرجة، واعتمد.
- القراءة التلقائية تحتاج إنترنت لتحميل المحرك، وهي أدق مع الخط المطبوع؛ خط اليد قد يحتاج الإدخال اليدوي.
